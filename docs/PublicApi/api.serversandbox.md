# `sandbox/api/generated.serversandbox.go`

## `ServerSandbox`

ServerSandbox is the server layer's part of the Sandbox: api.Sandbox embeds it, so its field is read as sandbox.Server. Generated by `agnos build` while server is on.

| Field | Type | Description |
| --- | --- | --- |
| `Server` | `Server` | Server is the http surface, built by the Constructor of sandbox/constructors/server. |
