## `Server`

Server is the http surface of the sandbox: every route the project declares, and the dispatch that reads a request against them. It is the OpinionatedAgnosServer contract's Server, built by sandbox/internal/server/generated.new.go, generated by `agnos build`.

`type Server = opinionatedagnosserver.Server`

## `ServeProps`

ServeProps describes one run of the http server: the address to listen on — host:port, a bare port, or a range of ports tried in turn — and its timeouts.

`type ServeProps = opinionatedagnosserver.ServeProps`
